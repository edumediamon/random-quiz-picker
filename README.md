# 랜덤 문제 추출기 (Quiz Picker)
사용자가 직접 준비한 JSON 또는 CSV 문제 데이터셋을 기반으로 자격증, 과목, 난이도 조건을 설정하여 문제를 공정하게 무작위(Fisher-Yates)로 추출하고 학습하는 독립 실행형 웹 애플리케이션입니다.

## 주요 기능
- **완전 독립 실행**: 별도의 Node.js 서버나 데이터베이스 없이 브라우저에서 `index.html`을 열어 즉시 사용할 수 있습니다.
- **다양한 파일 포맷 지원**: JSON 배열 및 RFC 4180 표준 CSV 파일의 드래그 앤 드롭 및 파일 업로드를 완벽 지원합니다.
- **동적 조건 필터링**: 업로드된 데이터의 자격증, 과목, 난이도 항목을 실시간 분석하여 조건 선택 드롭다운과 검색 기능을 자동 구성합니다.
- **Fisher-Yates 무작위 셔플**: 수학적으로 편향되지 않은 공정한 랜덤 추출을 보장합니다.
- **2가지 학습 모드**:
  - **1문제 즉석 풀이 모드**: 한 문제씩 집중해서 풀고, 정답/해설을 아코디언으로 확인하며 연속으로 다음 문제를 가져옵니다.
  - **N문제 시험지 묶음 모드**: 3개, 5개, 10개, 20개 또는 전체 문항을 무작위로 추출하여 시험지 형태로 확인합니다.
- **원클릭 전체 초기화**: 헤더의 `🔄 초기화` 및 데이터 관리 영역의 `🗑️ 데이터 비우기` 버튼으로 등록된 데이터셋, 필터, 문제 결과 및 세션 이력을 즉시 초기 상태로 리셋할 수 있습니다.
- **중복 문제 제외 (기본 적용)**: 세션 내에서 이미 출제된 문제를 추적하여 중복 출제를 방지하며, 실시간 풀이 진행률(`진행: N / M문제`)을 안내합니다.
- **출제 문제 TXT 파일 저장**: 출제된 단일 문제, 시험지 문제 묶음 또는 누적 출제 이력 전체를 사람이 읽기 편한 구조화된 텍스트(`.txt`) 파일로 다운로드할 수 있습니다.
- **인쇄 및 복사 편의**: 추출된 문제 모음을 시험지 형식으로 인쇄(`Ctrl+P`)하거나 마크다운/텍스트 형식으로 클립보드에 복사할 수 있습니다.
- **모던 비주얼 & 다크/라이트 테마**: 글래스모피즘과 세련된 색상 팔레트, 반응형 레이아웃을 제공합니다.

## 실행 방법
`index.html` 파일을 선호하는 웹 브라우저(Chrome, Edge 등)로 더블클릭하여 실행하거나, VS Code Live Server / 로컬 웹 서버로 열면 됩니다.

## 문제 데이터 작성 가이드
`data/sample-questions.json` 및 `data/sample-questions.csv` 파일을 예제로 참고하여 작성할 수 있습니다.

### 1. JSON 형식 예시
```json
[
  {
    "id": "q-01",
    "exam": "정보처리기사",
    "subject": "데이터베이스",
    "difficulty": "기초",
    "title": "SQL 조회 문법",
    "question": "employees 테이블의 모든 열을 조회하는 SQL 문은?",
    "options": ["SELECT * FROM employees;", "SHOW employees;"],
    "answer": "SELECT * FROM employees;",
    "explanation": "모든 열 조회 시 와일드카드(*)를 사용합니다."
  }
]
```

### 2. CSV 형식 예시
첫 번째 행은 헤더이며, 보기는 파이프(`|`) 기호로 구분합니다. 쉼표나 따옴표가 포함된 문장은 큰따옴표로 감쌉니다.
```csv
id,exam,subject,difficulty,title,question,options,answer,explanation
q-01,정보처리기사,데이터베이스,기초,SQL 조회 문법,employees 테이블의 모든 열을 조회하는 SQL 문은?,SELECT * FROM employees;|SHOW employees;,SELECT * FROM employees;,모든 열 조회 시 와일드카드(*)를 사용합니다.
```

### 지원 필드명 (한글 및 영문 별칭 자동 인식)
- **식별자**: `id`, `번호`, `문제번호`, `no`
- **시험/자격증**: `exam`, `자격증`, `시험`, `시험명`, `출처`
- **과목/관련 영역**: `subject`, `관련 영역`, `관련영역`, `영역`, `과목`, `분야`, `단원`
- **문제 유형**: `type`, `유형`, `문제 유형`, `문제유형`, `문항 유형`, `포맷`
- **난이도**: `difficulty`, `난이도`, `수준`, `등급` (기초, 보통, 심화 등)
- **제목**: `title`, `제목`, `주제` (생략 시 [유형] 문제 N 자동 생성)
- **문제 본문**: `question`, `문제`, `본문`, `질문`, `지문` (필수)
- **보기 목록**: `options`, `보기`, `선택지` (객관식인 경우)
- **정답/모범답안**: `answer`, `모범답안`, `모범 답안`, `모범정답`, `정답`, `답`, `해답` (필수, 배열 또는 단일값)
- **해설/풀이**: `explanation`, `해설`, `풀이`, `설명`, `해설 및 풀이`
