# 랜덤 문제 추출기 (Quiz Picker)
사용자가 직접 준비한 JSON 또는 CSV 문제 데이터셋을 기반으로 자격증, 과목, 난이도 조건을 설정하여 문제를 공정하게 무작위(Fisher-Yates)로 추출하고 학습하는 독립 실행형 웹 애플리케이션입니다.

## 주요 기능
- **완전 독립 실행**: 별도의 Node.js 서버나 데이터베이스 없이 브라우저에서 `index.html`을 열어 즉시 사용할 수 있습니다.
- **다양한 파일 포맷 지원**: JSON 배열 및 RFC 4180 표준 CSV 파일의 드래그 앤 드롭 및 파일 업로드를 완벽 지원합니다.
- **동적 조건 필터링**: 업로드된 데이터의 자격증, 과목, 난이도 항목을 실시간 분석하여 조건 선택 드롭다운과 검색 기능을 자동 구성합니다.
- **Fisher-Yates 무작위 셔플**: 수학적으로 편향되지 않은 공정한 랜덤 추출을 보장합니다.
- **2가지 학습 모드**:
  - **1문제 즉석 풀이 모드**: 한 문제씩 집중해서 풀고, 정답/해설을 아코디언으로 확인하며 연속으로 다음 문제를 가져옵니다.
  - **N문제 시험지 묶음 모드**: 3개, 5개, 10개, 20개 또는 전체 문항을 무작위로 추출하여 시험지 형태로 확인합니다.
- **원클릭 전체 초기화**: 헤더의 `🔄 초기화` 및 데이터 관리 영역의 `🗑️ 데이터 비우기` 버튼으로 화면 상태를 리셋할 수 있으며, `[풀이 이력 초기화]`로 현재 조건의 history 파일만 안전하게 비울 수 있습니다.
- **조건별 이력 분류 저장 및 중복 방지 (신규)**: 업로드한 문제 파일(JSON/CSV)과 추출 조건(자격증·영역·유형·난이도) 조합마다 프로젝트 폴더의 `history/` 아래에 개별 텍스트 파일(예: `history/내문제.json__정보처리기사__데이터베이스__전체유형__기초.txt`)로 분리 저장되어, 조건별로 독립적인 중복 배제가 이뤄집니다.
- **문제 소진 시 확인 후 초기화**: 중복 제외 상태에서 현재 조건의 미출제 문제가 없으면 초기화 확인창을 표시합니다. 취소하거나 초기화에 실패하면 현재 문제와 이력을 유지하며, 다른 조건의 미출제 문제를 계속 추출할 수 있습니다. 남은 문제가 요청 개수보다 적으면 남은 문제만 출제합니다. 검색어는 이력 분류 기준에 포함되지 않으므로 초기화 시 같은 조건의 다른 검색어 이력도 함께 지워집니다.
- **출제 문제 TXT 파일 저장**: 출제된 단일 문제, 시험지 문제 묶음 또는 누적 출제 이력 전체를 사람이 읽기 편한 구조화된 텍스트(`.txt`) 파일로 다운로드할 수 있습니다.
- **Google Drive 파일 직접 가져오기 (신규)**: 공식 Google Picker API 및 Google Identity Services를 연동하여 내 Google Drive에 저장된 문제 파일(.json, .csv 또는 Google Sheets)을 손쉽게 선택해 불러올 수 있습니다. API Key와 OAuth Client ID는 브라우저 설정 모달을 통해 간편하게 관리할 수 있습니다.
- **인쇄 및 복사 편의**: 추출된 문제 모음을 시험지 형식으로 인쇄(`Ctrl+P`)하거나 마크다운/텍스트 형식으로 클립보드에 복사할 수 있습니다.
- **모던 비주얼 & 다크/라이트 테마**: 글래스모피즘과 세련된 색상 팔레트, 반응형 레이아웃을 제공합니다.

## 실행 방법
1. **로컬 서버 실행 (추천 - `history/` 조건별 자동 파일 연동)**:
   터미널에서 아래 명령을 실행하면 프로젝트 폴더(`@random-quiz-picker/history`) 안에 조건별 TXT 파일이 실시간으로 자동 생성 및 분리 누적되며, 브라우저를 껐다 켜도 해당 조건의 문제들이 중복 제외 목록으로 자동 유지됩니다.
   ```bash
   npm start
   # 또는: node server.js
   # 브라우저 접속: http://localhost:3000
   ```
2. **독립 브라우저 실행**:
   별도 서버 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 더블클릭하여 바로 사용할 수도 있습니다. 이 경우 브라우저 내부 로컬 저장소(LocalStorage) 및 수동 TXT 다운로드 버튼으로 연동됩니다.

## Google Drive 연동 설정 파일 가이드
Google Drive 연동에 필요한 `Google OAuth Client ID`와 `API Key`는 아래의 **두 가지 방법 중 하나**로 설정할 수 있습니다.
- **방법 1. 설정 파일 사용 (로컬 서버 구동 시 권장)**:
  - **옵션 A (.env 파일)**: 프로젝트 루트의 [.env.example](file:///d:/dev/random-quiz-picker/.env.example)을 복사하여 `.env` 파일을 생성하고 아래와 같이 키를 입력합니다.
    ```env
    GOOGLE_CLIENT_ID=123456789-abcdef.apps.googleusercontent.com
    GOOGLE_API_KEY=AIzaSyYourApiKeyHere
    ```
  - **옵션 B (google-config.json 파일)**: 프로젝트 루트의 [google-config.example.json](file:///d:/dev/random-quiz-picker/google-config.example.json)을 복사하여 `google-config.json` 파일을 생성하고 아래와 같이 입력합니다.
    ```json
    {
      "clientId": "123456789-abcdef.apps.googleusercontent.com",
      "apiKey": "AIzaSyYourApiKeyHere"
    }
    ```
  - ※ `.env` 및 `google-config.json`은 `.gitignore`에 등록되어 있어 Git 커밋 시 외부에 노출되지 않습니다.
- **방법 2. 웹 UI 화면에서 직접 입력**:
  - 웹 화면 데이터 관리 패널에서 `[⚙️ Drive 설정]` 버튼을 클릭하여 나타나는 모달 창에 Client ID와 API Key를 입력하고 `[저장하기]`를 누르면 브라우저의 `localStorage`에 안전하게 영속 저장됩니다.

## 문제 데이터 작성 가이드
`data/sample-questions.json` 및 `data/sample-questions.csv` 파일을 예제로 참고하여 작성할 수 있습니다.

### 1. JSON 형식 예시
```json
[
  {
    "id": "q-01",
    "exam": "정보처리기사",
    "subject": "데이터베이스",
    "difficulty": "기초",
    "title": "SQL 조회 문법",
    "question": "employees 테이블의 모든 열을 조회하는 SQL 문은?",
    "options": ["SELECT * FROM employees;", "SHOW employees;"],
    "answer": "SELECT * FROM employees;",
    "explanation": "모든 열 조회 시 와일드카드(*)를 사용합니다."
  }
]
```

### 2. CSV 형식 예시
첫 번째 행은 헤더이며, 보기는 파이프(`|`) 기호로 구분합니다. 쉼표나 따옴표가 포함된 문장은 큰따옴표로 감쌉니다.
```csv
id,exam,subject,difficulty,title,question,options,answer,explanation
q-01,정보처리기사,데이터베이스,기초,SQL 조회 문법,employees 테이블의 모든 열을 조회하는 SQL 문은?,SELECT * FROM employees;|SHOW employees;,SELECT * FROM employees;,모든 열 조회 시 와일드카드(*)를 사용합니다.
```

### 지원 필드명 (한글 및 영문 별칭 자동 인식)
- **식별자**: `id`, `번호`, `문제번호`, `no`
- **시험/자격증**: `exam`, `자격증`, `시험`, `시험명`, `출처`
- **과목**: `subject`, `관련 영역`, `관련영역`, `영역`, `과목`, `분야`, `단원`
- **관련 영역**: `area_label` (명시적 과목과 별도로 유지)
- **출제 연도**: `year`, `연도`, `년도`, `출제연도` (네 자리 연도, 생략 가능)
- **문제 유형**: `type`, `유형`, `문제 유형`, `문제유형`, `문항 유형`, `포맷`
- **난이도**: `difficulty`, `난이도`, `수준`, `등급` (기초, 보통, 심화 등)
- **제목**: `title`, `제목`, `주제` (생략 시 [유형] 문제 N 자동 생성)
- **문제 본문**: `question`, `문제`, `본문`, `질문`, `지문` (필수)
- **보기 목록**: `options`, `보기`, `선택지` (객관식인 경우)
- **정답/모범답안**: `answer`, `모범답안`, `모범 답안`, `모범정답`, `정답`, `답`, `해답` (필수, 배열 또는 단일값)
- **해설/풀이**: `explanation`, `해설`, `풀이`, `설명`, `해설 및 풀이`

## 지문·모범답안에 LaTeX 수식 입력

F열 `type_label_question`(지문)과 G열 `model_answer`(모범답안)에 일반 글과 LaTeX를 함께 입력할 수 있습니다. 열 위치가 달라도 헤더 이름으로 인식합니다.

- 문장 안 수식: `전력은 $P = VI\cos\phi$입니다.` 또는 `\(x^2 + y^2\)`
- 독립된 수식: `$$\frac{a}{b}$$` 또는 `\[\sqrt{x}\]`
- 셀에는 위 예시의 역슬래시를 하나씩 입력합니다. JSON 파일에서는 역슬래시를 `\\`로 이스케이프해야 합니다.
- Excel에서는 셀을 텍스트 형식으로 지정해 입력하세요. `=SUM(...)` 같은 계산식이나 삽입된 수식 개체를 LaTeX로 자동 변환하지는 않습니다.

단일 문제와 시험지 화면 모두 수식을 표시합니다. 잘못된 수식은 원문으로 남고, TXT 저장·복사에는 입력한 LaTeX가 유지됩니다. KaTeX 0.19.0의 JS·CSS·폰트와 MIT 라이선스를 `vendor/katex/`에 포함하므로 수식 표시에 인터넷 연결이 필요하지 않습니다.

## 자격증·과목·영역·연도 연결

- `exam`은 자격증/시험명, `subject`는 과목, `area_label`은 관련 영역, `year`는 출제 연도입니다. 자격증을 선택하면 해당 과목만 표시하며, 자격증·과목을 바꾸면 관련 영역과 연도 선택지도 갱신합니다.
- 공공조달 원본은 A:G를 유지하고 H열 `exam`, I열 `year`, J열 `subject`를 사용합니다. 현재 192문항은 각각 공공조달관리사, 2026, 실기입니다. 과목 셀은 드롭다운 없이 직접 입력합니다. 필기 문항은 subject에 필기를 입력하세요.
- year는 2026처럼 네 자리 숫자로 입력합니다. 빈칸은 앱의 '연도 미지정'으로 구분합니다. 과목·영역·연도별 필터로 문제를 추출하고 카드·인쇄·TXT에서 함께 확인할 수 있습니다.
- 명시적 subject는 area_label과 별도로 읽으며, 열 순서에 영향받지 않습니다. 기존 area_label 전용 파일은 이전처럼 해당 영역을 과목으로 읽습니다. 기존의 다른 자격증 과목명도 계속 지원합니다.
- 연도와 관련 영역을 선택한 이력은 서버 history/와 브라우저 저장소에서 분리합니다. 같은 연도 내 다른 과목 및 서로 다른 연도의 동일 문제 번호도 중복 방지에서 구분합니다. 추가 필터가 모두 전체인 경우 기존 저장 키/파일명을 유지합니다. 기존 영역 과목에서 실기로 바뀐 조건의 이력은 삭제하지 않으며 자동 이전하지 않습니다.
- 로컬 앱 코드 변경은 원격 배포에 자동 반영되지 않습니다. 실행 중인 로컬 서버를 재시작한 뒤 앱을 새로고침하고 Drive 파일을 다시 불러오세요.

### 연도 필터 사용
1. Drive 또는 파일에서 문제를 다시 불러옵니다.
2. 자격증 공공조달관리사 → 과목 실기 → 출제 연도 2026을 선택합니다.
3. 필요하면 관련 영역을 선택하고 문제를 추출합니다.
4. 다른 연도의 문항을 같은 양식에 추가하면 해당 연도가 선택지에 나타나고 출제 이력도 선택 연도별로 저장됩니다.
