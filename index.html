랜덤 문제 추출기 (Quiz Picker) — 순수 브라우저 독립 실행형 웹 애플리케이션

☁️ Google Drive 연동 설정

Google Drive 연동 안내: 내 드라이브의 문제 파일(.xlsx, .csv, .json)을 직접 선택하여 불러오려면 Google Cloud API 키와 OAuth Client ID가 필요합니다.
  1. Google Cloud 콘솔에서 프로젝트 생성 후 Google Picker API 및 Google Drive API를 활성화합니다.
  2. OAuth 동의 화면 구성 및 웹 애플리케이션용 OAuth 2.0 클라이언트 ID를 생성합니다.
  3. 사용자 인증 정보에서 API 키를 발급받아 아래에 입력합니다.
🌐 Google 콘솔 [승인된 자바스크립트 원본] 등록 필수 주소:
http://localhost:3000
⚠️ 현재 로컬 파일(file://)로 열려 있습니다. Google OAuth 연동을 위해 start-server.bat를 실행하여 http://localhost:3000으로 접속해주세요.
※ 400 origin_mismatch 방지 팁: Google Cloud 콘솔의 OAuth 클라이언트 설정에서 http://localhost:3000 과 http://127.0.0.1:3000 두 개를 모두 승인된 원본에 추가해 두시면 주소창 접속 방식에 상관없이 오류가 발생하지 않습니다. (URL 끝에 / 슬래시를 넣지 마세요)
※ 입력하신 설정값은 브라우저(localStorage)에 안전하게 저장됩니다.

⚠️ 400 오류: origin_mismatch 해결 방법

Google 로그인 시 400 origin_mismatch 오류가 나타나는 이유는 현재 접속 중인 웹 주소가 Google Cloud Console의 [승인된 자바스크립트 원본]에 등록되어 있지 않기 때문입니다.

현재 접속 중인 주소 (이 값을 콘솔에 추가해야 합니다):
http://localhost:3000

🛠️ 해결 3단계:

  1. Google Cloud 콘솔 사용자 인증 정보 페이지 ↗로 이동합니다.
  2. 사용 중인 OAuth 2.0 클라이언트 ID 항목을 클릭하여 수정 화면으로 들어갑니다.
  3. [승인된 자바스크립트 원본] 항목에서 [+ URI 추가]를 누르고 아래 2개를 모두 입력한 뒤 [저장]을 누릅니다:
    • http://localhost:3000
    • http://127.0.0.1:3000
    ※ 주의: 주소 끝에 / 슬래시를 넣지 마세요.

💡 저장 후 구글 서버에 전파되기까지 약 1~2분 정도 소요될 수 있습니다. 저장 후 브라우저에서 다시 시도해주세요.
